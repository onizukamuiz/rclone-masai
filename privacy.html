Privacy Policy

Last updated: 12 November 2026

1. Application

Rclone Masai is a privately operated utility using rclone to access Google Drive and Google Workspace Shared Drives for authorised file management and backup.

2. Data Access

The application accesses Google Drive files and metadata only as authorised by the account owner. This may include listing, uploading, downloading, renaming and deleting files.

3. Data Usage

Google Drive data is used solely for file management, backup and data transfer. Data is not sold or used for advertising.

4. Data Storage and Security

Authentication tokens and configuration are stored locally on the authorised computer. File transfers are performed through Google's APIs using rclone.

5. Data Sharing

Google Drive data is not shared with third parties, except where necessary to provide the requested Google Drive services.

6. Contact

For privacy questions, contact the operator of Rclone Masai.
